PURPLE · A Moment
Wallpaper Engine Import Guide

1. Extract the entire PURPLE desktop interactive wallpaper ZIP archive, then open the PURPLE desktop wallpaper folder inside it.
2. Open Wallpaper Engine's wallpaper editor and drag index.html from that folder into the editor to create a Web wallpaper project.
3. If prompted to import other files from the same folder, import all of them. Keep the images, media, and other supporting files; do not copy only index.html.
4. Save the project, select this wallpaper in Wallpaper Engine, and apply it.

First Use and Resetting to Defaults

- Sound is enabled by default at volume 35. Use the speaker button or Settings to turn it off.
- The classic layout is shown and expanded by default; Immersive Mode is not enabled. Your selected layout, sound, and immersive state are remembered afterward.

Immersive Mode and Restoring the Interface

- Your choices to enter Immersive Mode manually and open the wardrobe are remembered automatically.
- In Wallpaper Engine's wallpaper settings on the right, find “Interface on Startup” and choose “Remember Last State,” “Start Immersed,” or “Show Interface.” The default on first use is “Remember Last State.”
- “Start Immersed” and “Show Interface” take effect when selected and are used on future reloads. During the current session, you can still open the wardrobe or enter Immersive Mode manually. Resuming playback or syncing settings again will not override those actions.
- Automatic hiding still hides the interface after 15 seconds of inactivity and shows it when you move the mouse; it is not saved as permanent Immersive Mode.

Moving Companion

- In the “A Moment to Cherish” wardrobe, selecting an outfit marked as a Moving Companion automatically enables Moving Companion mode.
- This package includes 9 Moving Companion outfits, each with its own dialogue, including “First Snow Fluff,” “Purple Mist Veil,” “Starlight at Night,” and later additions.
- “Night Owl Whispers,” “Moonwhite Lace,” “Soft Waves in Ink Night,” “Apricot Gauze Glow,” “Indigo Evening Breeze,” and “Apricot Knit Warmth” each have 10 ongoing companion lines, which rotate every 30 seconds during normal companionship.
- After 5 ordinary ongoing lines in a row, the next rotation shows an affectionate line; no extra cooldown is added.
- The first playback uses the entrance animation, then continuously loops the idle motion. “Single Outfit Loop” replays the full entrance.
- Use the playback menu at the bottom to switch manually to Still or another mode. Timed outfit changes and rotation retain the selected mode when they reach this outfit.
- Outfits without the Moving Companion marker keep their own Still, Single Outfit Loop, or Rotation behavior.

Wardrobe Browsing and Sorting

- Clicking one of the three wardrobe tabs only changes the list being browsed. Clicking an outfit cover changes the outfit.
- Use the control at the upper-right of the wardrobe to switch between ascending and descending order. Each wardrobe remembers its own setting; unavailable outfits stay at the end, and outfit numbers do not change.
- When browsing another wardrobe, the current video continues playing as before. “Return to Playback” takes you back to the outfit currently keeping you company.

Rotation Order

- Choose “In Order” or “Random” at the top of the playback menu. This applies to Rotate This Group, Favorites in This Group, Rotate All, and Favorites Across All.
- Playback is in order by default, and your choice is remembered. Random playback avoids repeats within each round and avoids playing the same outfit consecutively between rounds. If only one outfit is available, it continues looping.
- Ordered rotation follows the current ascending or descending order of each wardrobe.
- Changing the order keeps the current video. If an outfit change has already started, the new order takes effect after the handoff finishes. Still, Single Outfit Loop, Moving Companion, and “Occasionally Change Outfit” keep their own rules.

Occasionally Change Outfit

- In Still mode, the timer starts from the still frame. For regular outfits in “A Moment to Cherish” that have an exit animation, the current outfit resumes playing at the end of the timer and changes only after the exit animation finishes. Entrance and exit animations do not count toward the still duration; manually selecting an outfit still responds immediately.
- In Moving Companion mode, only outfits in the current group that support Moving Companion are selected, and the mode continues after changing outfits.
- The “All in This Group” and “Favorites in This Group” scopes are retained, and outfits do not repeat consecutively. If no eligible moving outfit exists, the timer pauses; if only the current outfit qualifies, it stays selected.
- The timer starts after the entrance animation and waits for the current cycle to finish before changing outfits. The timer pauses during playback pauses or while the control panel is open, and does not make up missed changes when resumed. Silent outfit changes still work while the interface is hidden or Immersive Mode is active.
- Timed outfit changes remain paused during Single Outfit Loop and rotation.
